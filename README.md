# MacroApp 🖱️⌨️

A lightweight macro automation tool for gamers. Record your keyboard and mouse actions, then replay them instantly — so you can focus on what matters.

---

### Features
- **Macro Recording** — Capture your keyboard and mouse clicks into a reusable macro.
- **Macro Playback** — Replay your recorded macros instantly with a single click.

---

### System Requirements
- **OS:** Windows (macOS not supported)
- **Storage:** Minimal

---

### How to Use
1. Download and extract `MacroApp.zip`
2. Run `MacroApp.exe`
3. Press **Record** to start capturing your actions
4. Press **Stop** when done
5. Press **Play** to replay anytime

---

### ⚠️ Warning
- MacroApp may not work on all applications
- Some games or software may block macro input due to anti-cheat or security systems
- Use at your own risk
